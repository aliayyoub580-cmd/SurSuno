# API Reference

This project includes a frontend API client and a backend Express API. The UI does not usually hit JioSaavn directly; it talks to the app’s own backend routes or its data service wrappers.

## Backend API

The backend server is started from [backend/server.js](../backend/server.js).

### Base URL

- Local development: `http://localhost:5100`
- Production / Vercel: generated by the hosting environment

### General Response Format

Most routes return JSON objects with either:

- `status: true` and data payloads, or
- `status: false` and an `error` field for bad requests or failures

### Endpoints

#### GET `/`

Redirects the user to the upstream JioSaavn API documentation site.

#### GET `/song/`

Search for songs.

Query parameters:

- `query` (required)
- `lyrics` (`true` or `false`)
- `songdata` (`true` or `false`)

Example:

```bash
curl "http://localhost:5100/song/?query=arijit%20singh&lyrics=true"
```

#### GET `/song/get/`

Fetch a single song by ID.

Query parameters:

- `id` (required)
- `lyrics` (`true` or `false`)

Example:

```bash
curl "http://localhost:5100/song/get/?id=abc123&lyrics=true"
```

#### GET `/playlist/`

Search or resolve a playlist by query or URL.

Query parameters:

- `query` (required)
- `lyrics` (`true` or `false`)

Example:

```bash
curl "http://localhost:5100/playlist/?query=https://www.jiosaavn.com/featured/xyz"
```

#### GET `/album/`

Search or resolve an album by query or URL.

Query parameters:

- `query` (required)
- `lyrics` (`true` or `false`)

#### GET `/artist/get/`

Fetch artist page details, metadata (name, photo banner, followers, verification status), and top songs.

Query parameters:

- `id` or `query` (required)
- `lyrics` (`true` or `false`)

Example:

```bash
curl "http://localhost:5100/artist/get/?id=arijit-singh"
```

#### GET `/lyrics/`

Fetch lyrics for a song by song link or song ID.

Query parameters:

- `query` (required)

Example:

```bash
curl "http://localhost:5100/lyrics/?query=https://www.jiosaavn.com/song/track/xyz"
```

#### GET `/result/`

Universal resolver for a JioSaavn URL or query text.

Query parameters:

- `query` (required)
- `lyrics` (`true` or `false`)

This endpoint can resolve song, playlist, or album entries based on the input.

#### GET `/news`

Returns the latest music and entertainment news articles.

Example:

```bash
curl "http://localhost:5100/news"
```

#### ALL `/news/update`

Triggers a news refresh and sync. It supports a shared secret for cron-triggered updates.

Headers or query:

- `x-cron-secret` or `secret`

Example:

```bash
curl -H "x-cron-secret: my-secret" "http://localhost:5100/news/update"
```

## Frontend API Client

The web app uses [src/services/musicApi.ts](../src/services/musicApi.ts) as its main client layer. It wraps `/api` and normalizes external JioSaavn payloads into the app’s TypeScript `Song`, `Album`, `Artist`, and `Playlist` models.

### Data Normalization

Key normalization logic includes:

- decoding HTML entities
- converting album cover sizes to larger image URLs
- deriving `media_url` and `download_url`
- filtering invalid records
- mapping JioSaavn result objects to app types

### Main exported helpers

- `searchSongs(query, withLyrics)`
- `searchAll(query)`
- `getSong(id, withLyrics)`
- `getSongByIds(ids)`
- `searchArtists(query)`
- `getArtistDetails(idOrName)`
- `getArtistSongs(idOrName)`
- `searchAlbums(query)`
- `getAlbum(id)`
- `searchPlaylists(query)`
- `getPlaylist(id)`
- `getLyrics(query)`
- `universalSearch(query)`
- `getTrendingSongs()`
- `getRecommendedSongs(songId)`


## Example Response Shapes

### Song object

```json
{
  "id": "abc123",
  "title": "Tum Hi Ho",
  "song": "Tum Hi Ho",
  "image": "https://.../500x500.jpg",
  "url": "/song/abc123",
  "duration": "260",
  "singers": "Arijit Singh",
  "primary_artists": "Arijit Singh",
  "album": "Aashiqui 2",
  "language": "hindi",
  "media_url": "https://.../song.mp3",
  "download_url": "https://.../song.mp3",
  "downloadAvailable": true
}
```

### News article object

```json
{
  "title": "A new chart-topper is trending in Bollywood",
  "description": "Music and entertainment coverage from a live RSS feed.",
  "image_url": "https://images.unsplash.com/...",
  "source_name": "SurSuno News",
  "article_url": "https://example.com/story",
  "published_at": "2026-08-25T00:00:00.000Z",
  "category": "Bollywood & Music"
}
```

## Notes

- Endpoints may return empty arrays or `null` values when upstream data is unavailable.
- JioSaavn and RSS feeds are external systems that can change structure without notice.
- The app intentionally includes graceful fallback logic so user experience remains stable.
